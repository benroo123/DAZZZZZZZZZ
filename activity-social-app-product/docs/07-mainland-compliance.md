# 中国大陆上线合规检查表

本文件是产品/工程检查清单，不替代律师、网信、通信管理部门或应用商店的正式意见。

## App 与账号

- 在境内从事互联网信息服务的 App 按工信部要求完成备案，并在显著位置标注备案编号。
- 对发布信息、即时通讯等用户落实适用的真实身份信息认证；未认证用户按规则限制信息发布能力。
- 提供便捷举报、申诉、账号注销、个人信息导出/更正/删除路径。
- 第三方 SDK 逐项披露目的、数据、频率、供应商和隐私政策，权限按场景即时申请。

## 个人信息与位置

- 精确定位和行踪轨迹属于高敏感场景，只有在同城/附近/签到需要时申请；取得单独同意，拒绝后提供按城市/区域浏览的降级能力。
- 资料字段设公开范围，默认最小公开；精确集合点只向已批准成员按时段开放。
- 实名供应商回调只落认证结果、时间和脱敏引用，尽量不保存身份证影像。
- 推荐、搜索、审核和 Agent 均执行同一拉黑与可见性策略。

## 推荐算法

- 在产品内说明推荐的基本原理、主要目的和运行机制。
- 提供关闭个性化推荐或不针对个人特征的选择，不能借关闭功能降低基本服务质量。
- 支持用户选择/删除用于推荐的标签或偏好；避免使用高敏字段进行不必要推断。
- 评估是否属于需办理算法备案的推荐服务，并在已发布信息中展示备案编号。

## 生成式 AI 图片

- 使用已完成相应备案/登记的模型服务；App/功能按适用要求公示模型名称及备案号或上线编号。
- AI 图片必须有用户可见的显式标识，文件或元数据含可追踪的隐式标识。
- 发布流程固定为“生成 -> 预览 -> 用户确认 -> 发布”，不能默认冒充用户直接发布。
- 保存模型、版本、任务、生成时间、媒体 hash、标识版本和确认记录；提示词先清除不必要个人信息。
- 提供重新生成、上传替代图片、投诉和删除生成内容的能力。

## UGC、消息与线下安全

- 帖子、活动、头像、评论、群聊和私信都进入分级内容治理体系；高风险交给人工。
- 建立未成年人保护策略、反骚扰限频、静默屏蔽、紧急分享和线下活动安全提示。
- 组织者修改时间/地点、取消活动、移除成员时记录审计并及时通知。
- 平台若未来组织超大规模线下活动、收费或代收款，应重新评估大型活动许可、电子商务和支付合规；50 人产品上限不能替代逐场风险评估。
